## D 盘一键复现

在本目录打开 PowerShell：

```powershell
.\check_Z.ps1 -DataPath 'D:\计算机视觉\rs_grounding_train_v1' -OutputPath 'D:\计算机视觉\Z_eval_outputs\v2'
```

该命令运行 32 项测试、重建完整评测输入、校验冻结名单、运行 oracle/全错和盲随机基线、独立评分，并核对原始训练包未变。需要 Python 3.10+，仅依赖标准库，无需模型或联网。脚本不会改变 PowerShell 执行策略。

原有 D 盘评测目录和原始训练包不作为输出位置。模型只读取生成目录中的 `protocols/<协议>/input_path/`；`private/` 仅评分器可读。

## 评分模型预测

```powershell
python evalkit.py score --gt 'D:\计算机视觉\Z_eval_outputs\v2\private\dev4_81_gt.json' --pred 'D:\计算机视觉\run_001\pred.json' --out 'D:\计算机视觉\run_001\metrics.json' --require-complete
```

主分公式：`0.1*R1 + 0.2*R5 + 0.6*Acc05 + 0.1*Acc75`。主分不采用同文多答案放宽；类别门控、多答案、类别平均均单列诊断。漏答默认计零；`--require-complete` 额外检查全覆盖。非法格式拒绝计分。

报告包括逐查询结果、各类别成绩、缺答数量、图片分组 bootstrap 95% 区间，以及预测、GT、评分器 SHA256。当前依照训练包公开规则实现，未取得官方隐藏评分脚本；类别错误、异常格式和坐标边界等未明确行为是明示的本地约定。

## 文件与阶段状态

- `evalkit.py`：构建、严格预测校验、评分与自检夹具。
- `blind_baseline.py`：只读公开输入的随机/整图弱基线。
- `test_evalkit.py`：32 项手算指标及异常格式测试。
- `splits/`：v2 冻结名单及源文件指纹；训练只读其 346 张清单。
- `audit/`：小型构建、基线和相似性审核摘要，不含原始标注/私有答案。
- `REPORT.md`：实际数据审核及自检结果。
- `docs/LOCAL_V2_README.md`：本机原使用说明存档，其中路径指向原 D 盘目录；本分支以本 README 为入口。

模型筛选停留在研究结论：D-FINE-S、RT-DETRv4-S、RS-M-CLIP、SigLIP 2 为候选，尚未在这里训练或宣布优胜。Z 本阶段交付评测基础；真实模型、Docker、断网计时及最终镜像大小验证仍待后续工作。
