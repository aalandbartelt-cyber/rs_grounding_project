# 当前可执行的 CPU 准备阶段

计划日期：2026-11-23。只新增本目录，不改变原始数据、冻结划分、原评分器和历史结果。所有大模型实验留到云 GPU。

| 阶段 | 当前执行内容 | 验收 |
|---|---|---|
| C0 冻结检查 | 校验 Z 分支、已跟踪文件指纹、1284 个数据源指纹；运行原有测试 | 原文件不变，无训练/开发图片重叠 |
| C1 数据审核 | 统计四类、原图短边分箱、密集程度、描述关键词与重复；生成训练样本审核队列 | 审核队列仅包含346张训练图的1913个目标；语义标记明确为粗筛 |
| C2 增强预览 | 按类别抽少量训练图，逐张生成温和光照、模糊、翻转、90度旋转与保框裁剪 | 框与像素同步，坐标可逆检查；几何样例限定纯检测，图文语义待审核 |
| C3 接口与诊断 | 输入只读的 adapter 接口、候选框侧文件、独立 GT 诊断、类别/图片/难度分组 | 手算案例证明候选漏检与选框错误可区分；主分仍调用原评分器 |
| C4 比较与迁移 | 同图配对 bootstrap、实验配置模板、固定退化评测输入、CPU一键复现和迁移包 | 同口径才能比较；测试夹具不作为模型成绩；未来真实模型可接同一接口 |

运行资源采用单进程与逐图处理，按处理检查点检查256MiB RSS预算。这个阈值是中止条件，不是操作系统硬限额。报告记录当前Python进程峰值，不把浏览器或全机占用算进来。

本次使用 Windows 自带 System.Drawing 逐图处理，无需安装图像库。Pillow 下载因网络审批取消而未完成，未继续尝试。没有安装 PyTorch、下载模型或启动训练。增强预览不是已确认有效的训练配方。

`export_augmented.py` 将固定346张训练图导出为分操作目录的带标注检测集，包括COCO、YOLO、Labelme JSON和training_manifest.json。类别映射明确：COCO/JSON为1至4，YOLO为0至3。原图副本之外的增强描述不直接作为图文监督，原文仅保存在审核字段中。`validate_augmented.py` 独立核对三种格式、图片指纹、框坐标、文本隔离和训练名单。

原始主评测输入保持不变。退化评测为独立目录，每个条件保持同样81张图库和相同查询，不把多个退化版本混入同一图库；只做辅助诊断。

图文定位几何增强首版默认关闭，因为关键词不能可靠区分图像坐标关系、物体自身结构关系和地理方向。光照/模糊样例仍需检查属性可辨认性。保框裁剪保留全部标注目标，但不保证保留文本中的未标注参照物，因此只标为检测样例。

候选覆盖率在最终框直接选自候选池时才是定位上限；模型会细化框或使用另一条路径时，覆盖率只用于诊断。候选存在但最终框失败，标为“选择/细化失败”，不武断断言一定是语言理解错误。

仍需云端完成：真实模型预测与速度验证、检测/图文微调、增强消融、多种子训练、教师验证与蒸馏、最终部署。无GPU夹具只能检验流程和诊断逻辑。
