## 任务

- **任务 A 图像检索**：给定中文描述，从 81 张 1024×1024 评测图中返回降序 `image_id`（至少前 5）
- **任务 B 区域定位**：给定 `image_id` + 中文描述，输出唯一框 + `category_id`
