## 决策原则

可实现性分三层：接口与程序能运行；8GB 本机或后续服务器能承担计算；留出集上有真实收益。通过前两层不等于第三层。最终追求有证据的质量，不承诺未经测试的最优成绩。

以固定 v2 图像划分为准：346 张用于训练、30 张用于日常开发、51 张原 val 用于阶段检查。首轮只在 dev 上评分，避免反复查看补充验证集。开发图与验证图都不进入训练。

P1 仅是可追溯的对照，不代表沿用仓库方案作为最终路线。已有权重训练经历不明，本阶段下载官方原始权重，固定 revision。

P1 中 Grounding-DINO 用固定英文类别提示产生候选，中文细节由 Chinese-CLIP 排序。这能分离候选生成与文本选框问题。排序分数、候选阈值、输入分辨率在运行前写入配置；不依据 query_id、标注序号或真值选框。不会把 P1 零样本结果当作微调后的上限。

P0 训练导出仅为训练可用的框做图像边界裁剪，保留原始框与裁剪记录；冻结评测原始浮点 GT 不变。开发/原 val 的标注副本放独立 evaluation_only/，训练文件绝不引用它们。

## 复现入口

1. `bootstrap.ps1`：D 盘独立 Python 环境及缓存，不更改系统 Python 包。
2. `prepare_data.py --data ... --out ...`：校验冻结图像划分、源文件 hash，导出训练与独立诊断数据；拒绝覆盖非空输出目录。
3. `download_models.py --out ...`：下载固定版本的官方原始权重与模型文件，不执行远程代码。
4. `baseline.py --input_path ... --output_path ... --models ...`：只读公开评测输入，真实模型预测。
5. `diagnose.py --gt ... --candidates ... --out ...`：独立读取 GT，计算候选覆盖上限；不参与模型推理。

实际进展与未通过条件记录于 STATUS.md。未经运行的阶段不会标为完成。
