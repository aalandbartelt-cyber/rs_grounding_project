# 争第一路线图：从 0.66 到 0.70

> 2026-11-19 · M
> 前提：实时榜第 1 = **0.6594**（3m36s）；我们的目标是 **≥0.70**，最低可接受 0.66。
> 依据：`docs/01_赛题审核与比赛思路.md`（数据实证、评分数学）、`docs/02_三人协作方案.md`（分工与门禁）

## 1. 先算清楚：0.70 从哪来

总分 `S = 0.1R1 + 0.2R5 + 0.6A50 + 0.1A75`。

假设我们能做到一个"强但非顶尖"的基线：

| 指标 | 基线假设 | 贡献 |
|---|---:|---:|
| R@1 | 0.45 | 0.045 |
| R@5 | 0.88 | 0.176 |
| Acc@0.5 | 0.58 | 0.348 |
| Acc@0.75 | 0.32 | 0.032 |
| **总分** | | **0.601** |

要到 0.70，需要 +0.099。最现实的加法：

| 提升项 | 增量 | 总分增益 | 难度 |
|---|---:|---:|---|
| Acc@0.5 0.58 → 0.70 | +12 点 | **+0.072** | 高（主战场） |
| Acc@0.75 0.32 → 0.45 | +13 点 | +0.013 | 中（框精修） |
| R@1 0.45 → 0.55 | +10 点 | +0.010 | 中高（模板上限） |
| R@5 0.88 → 0.94 | +6 点 | +0.012 | 低（切片+类先验） |
| **合计** | | **+0.107 → 0.708** | |

**结论：0.70 的 70% 来自 Acc@0.5 的 +12 点。** 不做定位突破，靠检索调参最多到 0.62–0.64，追不上第一。

## 2. 五个杠杆（按"每 GPU 小时增益"排序）

### L1 小目标 / 车辆（预期 +8~15 A50，成本 8–12h）

- 车辆：1022 框 / 7 图，中位短边 **16px**，是最大的失分源。
- 做法：
  1. `imgsz=1536` 对照（1024 基线）。
  2. 2×2 / 3×3 切片（重叠 15–20%），WBF 合并回原图。
  3. 车辆图重采样 + 光度增强（不旋转、不翻转改语义）。
  4. 若仍差：DIOR 公开数据预训练检测器，再微调 4 类。
- **验证**：车辆类 Acc@0.5 单独报；提升 <5 点就说明瓶颈不是分辨率，转 L3/预训练。

### L2 候选选择（预期 +5~10 A50，成本 6–10h）

- 多目标图 243/376（65%）；同类多目标时检测置信度选不准。
- 做法：Chinese-CLIP 裁剪图-文本相似度 + 颜色/尺寸/方位解析 + 几何特征（cx/cy/面积排名/到中心距离），listwise 训练，同图同类作硬负样本。
- **验证**：只在"同类多候选"子集上看增益；若 <3 点，降级为检测置信度。

### L3 检测容量 / 集成（预期 +3~6 A50，成本 6–8h）

- YOLO11m → YOLO11l/x；或 YOLO + RT-DETR 双模型 WBF。
- 镜像预算允许（YOLO11x ~110MB，RT-DETR-l ~130MB）；运行时 +1–2 分钟。
- **验证**：单模型先到瓶颈再集成；集成增益 <2 点就砍掉，省时间。

### L4 框精修 / 校准（预期 +3~5 A50、+8~15 A75，成本 4–6h）

- 按类别搜索框缩放因子（0.9–1.1）、最小框下限、长宽比修正。
- 多尺度 TTA（检测器可翻转；重排不翻）。
- IoU-aware 的框回归微调（可选）。
- **验证**：A75 单独看；A50 掉了就回退。

### L5 检索（预期 +0.01~0.02 总分，成本 4–6h）

- 切片 2×2/3×3 + max-pool、整图场景向量、类别存在性软过滤。
- 输出全量 81 个排序保 R@5；R@1 用场景语义补。
- **验证**：R@5 到 0.9+ 即止，不再投入。

### L6 VLM 重排（可选，预期 0~5 A50，成本 8–12h，高风险）

- 3B VLM（fp16 ~6GB）或 INT4 7B，仅对"同图多候选 + 低置信"的难例打分。
- 先做 20 条难例的可行性测试；若 +3 点且镜像/时不炸，才进主线。
- **不进入 P2/P3 主线**，只在 P4 前作为加分项。

## 3. 实验阶梯（每步都有 kill criterion）

| # | 实验 | 预期 | GPU 时 | 通过条件（dev4） | 不通过 |
|---|---|---|---:|---|---|
| E0 | YOLO11s @1024 基线 | — | 0.5 | 跑通，A50 ≥0.30 | 查数据/坐标 |
| E1 | imgsz 1536 | +2~4 A50 | 1 | 车辆 +3 点 | 回 1024 |
| E2 | 2×2 切片（车辆优先） | +5~10 A50 | 1.5 | 车辆 +5 点 | 查切片映射 |
| E3 | YOLO11m/l/x 容量 | +2~5 A50 | 2–3 | 比 E2 高 2 点 | 停在中号 |
| E4 | CLIP+几何重排 | +3~8 A50 | 3 | 多候选子集 +5 点 | 降级置信度 |
| E5 | 框校准 + TTA | +2~4 A50/+8 A75 | 1 | 总分 +0.01 | 回退 |
| E6 | YOLO+RT-DETR 集成 | +2~4 A50 | 2 | 总分 +0.008 | 砍掉 |
| E7 | 检索切片/融合 | +0.01~0.02 | 2 | R@5 ≥0.90 | 保基线 |
| E8 | 全量 427 重训（固定 epoch） | +1~3 A50 | 2 | val 不降 | 回 train-only |
| E9 | VLM 难例（可选） | +0~5 A50 | 8–12 | 难例 +5 且时 <8min | 放弃 |

**每一步只改一个变量；dev4 总分提升 <1.5 点视为噪声，不进入下一轮。**

## 4. 数据策略

1. **dev4**：从 train 分层抽 30 图（车辆 2、舰船 8、油罐 8、飞机 12），只用于选模。
2. **train_minus_dev4**：选模阶段的训练集。
3. **最终模型**：用全部 427 图（train+val）重训，epoch 由 dev4 早停确定；报告里注明"最终模型见过 val"。
4. **禁止**：val 调参、按框随机划分、同图跨 split。
5. **公开数据**：DIOR/DIOR-R 只用于预训练；类别映射写清楚；许可写进报告。

## 5. 运行时与镜像

- 目标端到端 **4–6 分钟**（第一 3m36s，第二 1m50s；同分按用时）。
- 10GB 方案：CUDA torch + YOLO11x + CLIP B/16 +（可选）RT-DETR，约 4–5GB。
- 2GB 方案：ONNX Runtime + YOLO11m.onnx + CLIP ONNX（fp16/int8），约 0.6–1.2GB；CPU 推理 <15 分钟。
- 时间守卫：>45 分钟切快速路径；所有异常写合法 `pred.json`。

## 7. 失败模式与止损

| 失败模式 | 识别信号 | 止损 |
|---|---|---|
| 车辆切片没效果 | 车辆 A50 提升 <5 点 | 转 DIOR 预训练/专用检测器；不做无限切片 |
| 重排没效果 | 多候选子集 <3 点 | 降级为检测置信度，省 3 小时 |
| 集成没效果 | 总分 <+0.008 | 砍掉，保运行时 |
| 线上远低于本地 | 差 >10 点 | 查 split/坐标/类别/strict-anydup/查询抽样 |
| 时间超限 | 端到端 >45 分钟 | 关 TTA/集成，切快速路径 |
| 镜像超限 | tar > 上限 | 切 ONNX/量化/去 DINO |

## 8. 一句话

**要第一，必须拿下"小目标检测"和"多候选选择"这两个突破；检索只要做到 0.9 R@5 不拖后腿。0.70 不是靠调参堆出来的，是靠 E2 + E4 两个 5–10 点的跳跃。**
